# global-cms

# 🤖 Telegram Media Sync Engine

Автоматизована система синхронізації та публікації медіафайлів (фото, відео, анімацій) з хмарного сховища **Google Drive** у канали та чати **Telegram** за допомогою **GitHub Actions**.

---

## 📑 Структура проекту

```text
├── .github/
│   └── workflows/
│       ├── telegram_sync.yml     # Сценарій: Сімейний Архів (2 рази на день)
│       └── photo_exchange.yml    # Сценарій: Щотижневий Фотообмінник (Щонеділі)
├── downloaded/                   # Тимчасова папка для обробки медіа (створюється динамічно)
├── main.py                       # Основний керуючий скрипт синхронізації
├── requirements.txt              # Локальні залежності Python
└── README.md                     # Ця документація

⚙️ Логіка роботи (Алгоритм)Скрипт працює за принципом "Один запуск — Один якісний альбом", щоб не спамити у чат великою кількістю повідомлень та обходити обмеження Telegram API.[Google Drive Папка] ──> Завантаження файлів ──> Читання метаданих (EXIF/.mp4)
                                                               │
[Проміжний Кошик] <── Переміщення <── Відправка Альбому <── Конвертація/Стиснення
1. Сканування та ЗавантаженняБот підключається до Google Drive через Сервісний Акаунт.Перевіряє цільову папку на наявність нових файлів (ліміт сканування — 50 об'єктів за раз).Файли з непідтримуваними розширеннями ігноруються та залишаються в папці.2. Визначення Реальної Дати та ЛокаціїДля правильного групування скрипт шукає дату зйомки за наступним пріоритетом:Для фото: EXIF-тег DateTimeOriginal.Для відео/анімацій: Внутрішні метадані контейнера через ffprobe (creation_time).Резервний варіант: Порівняння параметрів createdTime та modifiedTime на Google Диску. Обирається найстаріша дата (захист від затирання дати при копіюванні).Для GPS: Витягуються координати. Якщо вони є — через OpenStreetMap Nominatim визначається назва міста та країни українською мовою.3. Оптимізація форматів під TelegramHEIC/HEIF: Автоматично конвертуються в якісний .jpg.GIF / SWF: Перетворюються у стабільні .mp4 відеофайли за допомогою ffmpeg.Важкі/Неформатні відео: Відеоформати (.mov, .avi, .mkv, .3gp) або відео розміром понад 49 МБ стискаються кодеком H.264 (libx264), щоб гарантовано пройти ліміт Telegram (50 МБ для звичайних ботів).4. Розумне групування та ПублікаціяУсі підготовлені медіа сортуються в групи за ключем: [Дата + Локація].За один запуск публікується лише перша знайдена група.Якщо всередині цієї групи міститься понад 10 файлів, скрипт відрізає перші 10 штук, формує красивий Telegram-альбом (sendMediaGroup), додає підпис (наприклад: 📅 12.09.2018 📍 Штутгарт, Німеччина) та відправляє.Решта файлів залишаються чекати наступного запуску.5. Очищення сховищаЯкщо альбом успішно доставлено в Telegram, надіслані файли автоматично забираються з робочої папки Google Drive та переміщуються у Проміжний Кошик ID (TRASH_FOLDER_ID), захищаючи чат від повторів.🗂️ Підтримувані формати файлівТипФорматиОбробкаЗображенняjpg, jpeg, png, webp, tif, tiffНадсилаються як фото, читається EXIFApple Фотоheic, heifКонвертуються в jpeg перед надсиланнямАнімаціїgif, swfКонвертуються через ffmpeg в mp4 відеоВідеоmp4, mov, avi, mkv, 3gp, mpeg, mpgПеревірка ліміту 50МБ, стиснення в H.264 / AAC🔐 Налаштування GitHub SecretsДля роботи воркфлоу в налаштуваннях репозиторію (Settings -> Secrets and variables -> Actions) мають бути додані такі секрети:GDRIVE_SERVICE_ACCOUNT_KEY — Повний вміст JSON-файлу ключа сервісного акаунта Google.TELEGRAM_BOT_TOKEN — Токен вашого бота від @BotFather.TELEGRAM_CHAT_ID — ID основного чату для Сімейного архіву (починається з -100).
